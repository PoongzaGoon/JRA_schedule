# 독립 GitHub 저장소

사용자가 생성한 새 저장소: https://github.com/PoongzaGoon/JRA_schedule

초기 요청 이름은 `JRA_Schedule_for_each_stallion_by_capture_method`였지만, 저장소 생성 API가 거부되어 사용자가 직접 생성하고 제공한 `JRA_schedule` 주소를 사용합니다. 기존 `JRA_Schedule_for_each_stallion`과 Git 이력·코드·원격 저장소가 분리되어 있습니다.

사용자의 후속 승인에 따라 **공개 저장소**로 시작합니다. 저장소 Settings → General → Danger Zone → Change repository visibility에서 Private로 바꿀 수 있습니다(소유권·조직 정책에 따라 제한될 수 있음). 이미 외부에서 복사한 코드까지 회수되지는 않습니다.

개발 파일은 PC방 컴퓨터가 아닌 클라우드 작업 공간에서 작성했습니다. PC방에 소스를 내려받거나 개발 도구를 설치할 필요 없이 GitHub에서 소스를 검토할 수 있습니다. 실제 웹사이트 운영 배포는 별도 승인 대상입니다.

`.env`, SQLite 파일, 실제 캡처, 실제 전사 데이터는 커밋하지 않습니다. 운영 비밀값은 호스팅 설정에 둡니다. 포함된 JSON과 화면 예시는 모두 가상 자료이며 실제 캡처 전사가 아닙니다. 저장소 공개 범위와 웹사이트 공개 범위는 별개입니다.
