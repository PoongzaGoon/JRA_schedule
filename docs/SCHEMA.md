# 캡처 기반 출주표 스키마 1.0.0

첨부된 '이번 주 출주마' 표의 기본 열과 부가 열을 담습니다. 기존 사이트의 종마별·날짜별 그룹 구조를 따르되 새로운 독립 스키마를 사용합니다. 이 스키마는 기존 저장소의 JSON 파일과 직접 호환되지 않습니다.

## 최상위

| 필드 | 의미 |
| --- | --- |
| `schemaVersion` | 반드시 `1.0.0` |
| `isExample` | 실제 전사 자료는 false, 가상 예시는 true. 화면 예시 표시 유지 |
| `referenceDate` | 관리자가 제공하는 자료 기준일 YYYY-MM-DD |
| `sourceUrl` | 원본의 HTTPS URL, 추측 금지 |
| `notes` | 공개 가능한 자료 메모, 없으면 null |
| `stallions` | 종마 목록. 각 종마는 id/name/sourceUrl/raceDays |

실제 게시 시각과 게시본 ID는 서버가 생성하며 입력 JSON에는 넣지 않습니다. 종마의 `sourceUrl`이 null이면 최상위 출처를 사용합니다.

## 이름·번역 표기

경마장, 경주명, 종마명, 마명, 기수, 조교사는 동일한 객체 구조입니다.

```json
{"ja":"原文","ko":"한국어 표기","koKind":"ai"}
```

- `official`: 관리자가 공식 한국어 표기로 확인한 값. 서버가 공식성을 인증한다는 뜻은 아닙니다.
- `ai`: AI 번역 또는 음역.
- `unverified`: 추가 확인이 필요한 표기.
- 원문/번역이 판독되지 않으면 해당 값을 null로 둡니다. 한국어가 있으면 koKind를 지정해야 합니다.
- 종마 name 객체 자체는 필수입니다. 행의 이름 필드는 객체 전체를 null로 둘 수도 있습니다.

## 날짜별 출주 행

| 필드 | 대응 열 / 허용 값 |
| --- | --- |
| `raceNumber` | R, 1~12 또는 null |
| `venue` | 場, 경마장 원문/한국어 |
| `raceName` | レース名, 경주명 원문/한국어 |
| `surface` | 芝=turf, ダ=dirt, 장애=jump, 불명=null |
| `distanceM` | 코스 거리(m), 숫자 또는 null |
| `horse` | 馬名, 원문/한국어 |
| `sex` / `age` | 牡=male, 牝=female, セ=gelding / 나이 정수 |
| `jockey` | 騎手, 원문/한국어 |
| `weightKg` | 斤量, kg 숫자 또는 null (0.5 단위) |
| `review` | required boolean, notes string 또는 null |
| `extras` | 아래 부가 열. 이미지에 없거나 뜻이 불명확하면 null |

extras 키: `popularity`(인기), `gate`(게이트), `horseNumber`(마번), `trainer`(조교사), `finishPosition`(착순), `previousRace`(이전 경주 텍스트), `interval`(간격 원문 텍스트).

`前人` 등 축약 열의 의미를 확인하지 못하면 인기·착순을 임의로 대입하지 마세요. `raceNumber`와 `horseNumber`는 다릅니다. 馬主·馬体重 등의 다른 열이 필요하면 다음 스키마 버전으로 추가합니다. 스키마에 없는 키는 거부됩니다.

## 오류와 경고

**게시 차단:** JSON 문법, 스키마·타입·날짜·숫자 범위, 알 수 없는 키, 중복 종마 ID, 중복 날짜 그룹, 같은 날짜·경마장·경주·마명의 중복 행, 한국어 표기의 출처 종류 누락, 2,000행 초과.

**검토 경고:** 주요 필드 null/번역 누락, unverified, review.required, 가상 예시, 전체 행 없음. 부가 열 null은 정상이며 경고를 만들지 않습니다. 빈 문자열 대신 null을 사용하세요.

원문 경마장·마명과 경주 번호가 없으면 중복 판정 근거가 부족합니다. 이 경우 누락 경고를 확인하고 관리자가 원본과 대조해야 합니다. 스키마를 통과해도 캡처의 행 누락·OCR 오독·부정확한 번역을 자동 판별하지는 못합니다.

각 날짜 그룹에는 `date`, `entries`를 넣고 순서를 유지하세요. 빈 entries는 출주 행이 없음을 뜻합니다. 기간·요일·행 수는 화면에서 데이터로부터 계산합니다.
